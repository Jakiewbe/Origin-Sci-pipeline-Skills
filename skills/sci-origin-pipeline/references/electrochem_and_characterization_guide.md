# 衍射、物性表征与一次锂电池电化学数据物理护栏

## 1. 课题体系核心物理红线（严禁违背）

当处理 `Li / CFx` 一次转化型锂电池体系数据时，Agent 必须遵守以下科学表述边界：
1. **一次转化型电池属性**：反应机制为 $\text{CF}_x + x\text{Li}^+ + x\text{e}^- \rightarrow \text{C} + x\text{LiF}$，属于**一次锂电池**，严禁套用二次摇椅式锂离子电池的“充电化成”、“可逆脱嵌循环”等错误术语。
2. **脉冲恢复工步术语严格区分**：
   - 脉冲后接 `1 C, 60 s` 的阶段仍存在恒流负载，必须称为**“1 C 恒流恢复”或“带负载准恢复”**，严禁称为“开路静置弛豫（OCV relaxation）”。
   - 只有电流严格满足 $I = 0$ 的工步才能称为**“静置恢复（Rest recovery）”**。
3. **短脉冲压降物理诠释克制**：
   - 新威测试仪在 `0.1 s` 级采样率下记录的第一采样点电压突降 $\Delta V_0$，必须表述为**“第一采样点表观压降（First-sample apparent voltage drop）”**，包含欧姆内阻、极快电荷转移与双电层瞬态过程，**严禁直接等同于纯欧姆内阻 $I R_{\Omega}$**。
   - `100 C – 225 C`（`0.5 – 2.0 s`）属于极端大电流短时强脉冲，严禁称为线性小信号扰动。

## 2. 各模态数据解析与作图预设规范

### 2.1 XRD 粉末与极片衍射（`.rasx` / `.txt` / `.asc`）
- **文件优先顺序**：Rigaku SmartLab 导出的 `.rasx`（本质为包含 `Data0/Profile0.txt` 与测量条件 XML 的无损 ZIP 包）或 `.txt` 优先于 `.asc`。
- **特征峰位参考（Cu $K\alpha$, $\lambda = 1.5406\ \text{\AA}$）**：
  - `CFx (001)` 层间衍射峰：`~12.5°–14.2°`（由 Bragg 公式 $d_{001} = \lambda / (2\sin\theta)$ 计算层间距膨胀度）；
  - 石墨化碳 `C (002)`：`~25.5°–26.5°`；
  - 放电产物立方相 `LiF`（PDF#04-0857）：`(111)` 在 `38.7°`、`(200)` 在 `45.0°`、`(220)` 在 `65.5°`；
  - 极片集流体基底峰（如 Al 箔 `38.5°, 44.7°, 65.1°` 紧邻 LiF 峰位！**分析涂覆在铝箔上的极片 XRD 时，必须主动提醒核查 Al 集流体衍射峰与 LiF (111)/(200)/(220) 的重叠效应！**）。

### 2.2 FTIR 傅里叶变换红外光谱（`.CSV` / `.SPA`）
- **横坐标规范**：红外光谱按化学惯例采用**高波数在左、低波数在右（`4000 → 400 cm⁻¹`，`invert_x = True`）**。
- **关键化学键判据**：
  - 共价型 `C-F` 伸缩振动：`~1215 cm⁻¹`；
  - 半离子型 `C-F` 特征吸收带：`~1100–1140 cm⁻¹`；
  - 边界 `-CF2` 对称/反对称振动：`~1250–1350 cm⁻¹`。

### 2.3 EIS 电化学阻抗谱与 DRT（`.txt` / `.z60` / `.csv`）
- **铁律：Nyquist 图必须强制 `1:1` 等比例坐标轴（Equal Aspect Ratio）**！若横纵轴比例不等，45° Warburg 扩散尾线与半圆弧度将严重失真，审稿人一眼拒稿。
- **符号约定**：纵轴统一取电容性正值 `$-Z'' (\Omega)$`。当低频扩散阻抗跨度远大于高频半圆（> 10 倍）时，自动在右上/左上空白区添加高频局部放大内插图（Inset，同样保持 1:1 等比例）。
- **机理边界**：EIS（线性小信号频域响应）与 DRT 弛豫时间分布仅与强脉冲极化做**定性趋势互证**，不得将某个 DRT 峰与强脉冲时间域压降做点对点机械等同。

### 2.4 BET 比表面积孔径、粉体电导与激光粒度
- **BET（`.csv`）**：吸脱附等温线使用同色实心点（Adsorption）与空心点（Desorption）区分滞后环；孔径分布标注具体模型（BJH 介孔 vs. DFT 全孔径）。
- **激光粒度（Mastersizer `.xls`）**：横坐标必须采用 **对数坐标（Log10 Scale，`0.1 – 1000 μm`）**，并在汇总表中标明 $D_{10}$、$D_{50}$、$D_{90}$。
