# 工作卡三 · 审查结论

**核心回答**：**哪一条原始证据支持这个结论？哪些选择会改变它？**

---

## 执行清单

1. **核对计算口径、分组与自由度一致性**
   - 检查样本代号、对照组归属、横纵坐标单位、归一化分母以及误差棒口径（明确标清 `Mean ± SD`、`Mean ± SEM` 还是 `95% CI`），确认未将技术重复误作独立样本放大显著性。

2. **分领域核查最敏感的风险环节**
   - **谱学分峰与表征任务**：重点核查 `quality_audit.json` 与拟合结果表：
     - **残差与参数触界（Bound Pinning）**：检查 `NRMSE (%)` 是否异常或存在系统性波浪残差，以及各子峰 `Center` / `FWHM` 是否顶死上下界（`CEN_BOUND` / `WARN_CENTER_AT_BOUND`）——重叠谱区即使 $R^2 > 0.999$，参数触界仍会导致组分面积比例严重失真（见 [氟化碳 F 1s 四模型案例](./case_cfx_xps_and_f1s_models.md)）；
     - **弱信号与基底峰干扰**：`SNR < 3.5`（`INFO_TRACE_SIGNAL`）谱区不得解读为确定性含量变化；极片衍射叠谱须核查集流体强峰是否压扁活性相归一化强度。
   - **生物统计、组学、药理拟合与临床生存/ROC 任务**：
     - **多重比较与效应量**：核对 `Statistical_Tests` 表中的 `p_raw` 与校正后 `p_adj`（`fdr_bh` / `holm` / `bonferroni`）及效应量（Cohen's $d$ / $\eta^2$ / $\log_2\text{FC}$ / `HR`），区分“统计显著但效应微弱”与“兼具统计和实际效应显著”；
     - **生存曲线与诊断评估门禁**（`validator.audit_survival_and_roc`）：核查高删失率或随访末期 `Number at risk` 极低导致的尾部阶梯剧烈跳变（末段不可过度解读为长期平台），以及重度正负样本失衡下高 `AUROC` 掩盖低精确率（须对照 `AUPRC` 与阳性率基线）；
     - **非线性曲线拟合稳健性**：核查 `Curve_Fit_Summary` 中 `IC50` / $K_m$ / $E_a$ 的标准误与置信带宽度，检查实验浓度范围是否真正覆盖上下渐近平台（未达平台时外推 `IC50` 须标明不确定性）。
   - **跨领域物理闭合门禁**：电池测试缺活性物质质量时确认已拦截比容量换算并标记 `WARN_MISSING_ACTIVE_MASS`；三元相图确认三组分之和闭合核验无异常偏差；短脉冲压降拆解确认无负欧姆压降或明显自热异常。

3. **证据链分层与审计标记同步落盘**
   - 每条主要结论必须可追溯到具体输入文件、谱区/队列/工步及对应图面板与 `Source_Data.xlsx` 行号。
   - 严格区分**跨合理模型一致成立的稳健结论**与**随分峰边界、显著性阈值或异常点剔除而改变的敏感结论**。
   - **风险警告不剥离**：`INFO_TRACE_SIGNAL`、`WARN_CENTER_AT_BOUND`、`WARN_MISSING_ACTIVE_MASS` 及统计多重校正说明必须保留在最终 `Source_Data.xlsx` 与图注汇报中。

## 本卡输出（交给工作卡四与最终汇报）

- `稳健结论（附原始数据与检验统计量指针）`
- `方法/参数敏感性波动区间（如有）`
- `必须同步写入图表与 Source_Data.xlsx 的质量与统计审计标记`
