# 工作卡一 · 核对数据

**核心回答**：**这批数据是什么？它能支持用户想做的比较吗？**

---

## 执行清单

1. **打开真实文件与说明，调用 6 大学科包自动嗅探，不凭文件名猜内容**
   - 先运行 `invoke_sciorigin.ps1 list-packs`、`scan "<dir>"` 与 `inspect "<file>"`，读取配套说明文件、工作表标题（`Titles` / `Peak Table` / 新威 `Step.xml`）或结构化表头。
   - 引擎自动跨 6 大学科包嗅探解析：材料/电化学（`.xls/.xlsx/.vms/.vgd/.rasx/.asc/.spa/.z60/.cor/.ndax/.nda/.dsc/.dta/.qps`）、化学波谱 JCAMP-DX（`.jdx/.dx/.jcamp`）、射频/光学网络参数（`.s1p/.s2p`）、生物流式/质谱/单细胞元数据（`.fcs/.mzml/.h5ad`）、机器学习训练日志流（`.jsonl`）及通用表格（`.csv/.tsv`）。
   - 对同名或相近命名文件逐一核对内部工作表名称、谱区范围与真实信号特征。

2. **确认四要素映射**
   - **样品、分组与对照关系**：明确列出每个文件/数据列对应的实验组、阳性/阴性对照或基线模型（如 `Control` vs `Treatment`、`Pristine` vs `Passivated`、`Full Model` vs `Ablation`）。
   - **数据结构与数据类型**：明确区分**原始仪器谱/时间序列/个体观测记录**、**仪器自动导出汇总**与**既有拟合/统计结果**。
   - **坐标物理量、编码与单位**：核对横纵坐标量纲与方向（如结合能 `eV` 与核磁化学位移 `ppm` 反演横轴、光学波长 `nm` 与光子能量 `eV` 换算、EIS `-Z''` 符号、生存分析 `time >= 0` 且 `event ∈ {0, 1}`、三元组成 `A + B + C = 100%` 闭合性）。
   - **重复层级（严防伪重复 Pseudoreplication）**：严格区分**同一样品的多个技术重复/微区测点**（如同一极片 3 个 Raman 微区，应先按微区聚合成单样品均值后再做组间推断）与**独立生物学/批次平行样本**（`n` 的真实自由度来源）。

3. **检查信号质量、样本量与硬性缺项**
   - **谱学信噪比**：核查弱信号谱区是否为本底噪声（`SNR < 3.5`，标记 `INFO_TRACE_SIGNAL`）。
   - **统计与生存/ROC 样本完备性**：检查各组有效样本量 `n`（`n < 3` 无法稳健检验正态性或计算四分位核密度）、生存队列删失比例与尾部在险人数、ROC 正负样本数（`n_pos`, `n_neg` 是否均非空及是否存在严重类别失衡）。
   - **点明分母缺项及安全降级边界**：若缺少关键换算分母（如电池测试缺**活性物质质量 `mg`**、催化缺电极几何/活性面积、力学缺原始截面积与标距），明确指出当前**有依据能直接交付的原始量**（如 `Capacity (mAh)`）与**必须补充前提后才能折算的派生量**（如 `mAh g^-1`）。

## 本卡输出（交给工作卡二或直接向用户汇报）

- `研究问题与匹配学科包 (pack_id)`
- `数据清单与样品/组别/重复层级映射`
- `可用特征、坐标单位与质量初筛（弱信号 / 样本量 / 删失率 / 闭合性）`
- `数据缺项与前置阻断或安全降级说明`
