# 工作卡一 · 核对数据

**核心回答**：**这批数据是什么？它能支持用户想做的比较吗？**

---

## 执行清单

1. **打开真实文件与说明，不凭文件名猜内容**
   - 先运行目录侦察与文件细查工具（如 `invoke_sciorigin.ps1 scan "<dir>"` 与 `invoke_sciorigin.ps1 inspect "<file>"`），读取配套说明文件（`0数据说明.txt`、`Titles`、`Peak Table`、新威 `Step.xml`、CSV 表头）。
   - 对同名或相近命名文件（例如不同样品目录下的 `1.xls` 与 `Cu1.xls`、`S1_spot1.txt` 与 `S1_spot2.txt`）逐一核对内部工作表名称、标题路径与信号特征。
2. **确认四要素映射**
   - **样品与分组**：列出每个样品/工步对应的数据文件、对照组 vs 处理组关系（例如“盐雾前 Cu (`1.xls`) ↔ 盐雾后 Cu (`Cu1.xls`)”）。
   - **数据结构与数据类型**：明确区分**原始仪器谱/测试数据**、**仪器自动导出汇总**与**已有分析/拟合结果**。
   - **谱区/工步与列单位**：核对横纵坐标物理量及单位（例如 `eV` / `Counts/s`、`mAh` vs `mAh g^-1`、`-Z''` 符号）。
   - **重复层级**：判定多个文件或表格是**同一样品的多个微区测点**（如 Raman 3 测点应先单谱拟合再算均值±SD），还是**独立平行样品/电池**。
3. **检查信号质量与硬性缺项**
   - 核查哪些谱区或曲线实际存在有效信号（例如 Cu 样中 `Ni 2p` 或未放电 CFx 样中 `Li 1s` 是否仅为本底噪声 `SNR < 3.5`）。
   - **点明缺项及受影响结论**：若缺少计算关键比值所需的分母或前提信息（例如新威倍率测试缺少**活性物质质量 `mg`**，或缺少测试面积、空白对照、激光波长），明确指出：
     - 当前**有依据**能做什么（如比较原始容量 `mAh`、电压平台与能量 `mWh`）；
     - 当前**不能做**什么（如不能折算 `mAh g^-1` 或 `Wh kg^-1`，必须向用户确认分母后才能换算）。

## 本卡输出（交给工作卡二或直接向用户汇报）

- `研究问题`
- `数据清单与样品映射`（文件 → 样品/组别/工步/测点 + 数据形态）
- `可用特征与单位`（含弱信号谱区标记）
- `数据缺项与前置阻断/降级说明`
