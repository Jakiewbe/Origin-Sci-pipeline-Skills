# 完整参考案例：Li/CFx 极片 XPS 分峰与 F 1s 四组候选模型决策过程

> **定位声明**：本文件记录氟化碳（`Li/CFx`）电极体系的科学决策链示例（对应工作卡一～四），所有特定峰位、边界阈值与子体系归属仅在本案例及 [xps_cfx_battery_presets.json](../presets/xps_cfx_battery_presets.json) 中维护，**不作为其他材料体系（如金属镀层盐雾、过渡金属氧化物、常规硅碳负极）的默认模板**。

---

## 1. 工作卡一：数据核对（以未放电极片 `Sample 1` 为例）

- **原始文件**：Thermo Avantage 导出 `.xls`（配套若存在未经 TXFN/dwell 校正的原始 `.VGD`，定量优先读校正后的 `.xls`）。
- **工作表与谱区确认**：`XPS Survey`、`C1s Scan`（279–298 eV）、`F1s Scan`（678–698 eV）、`O1s Scan`（525–545 eV，`SNR > 20`）、`Li1s Scan`（50–62 eV，`SNR < 3.5` 属痕量/本底边缘）。
- **样品条件**：`Sample 1` 为**未放电态 CFx 正极极片**（含氟化碳活性物质 + 导电炭 + PVDF 粘结剂），而非放电态富含 `LiF` 的极片。

---

## 2. 工作卡二：方法选择与四组 F 1s 候选模型

### 2.1 为何采用 `xps_cfx_battery_presets.json`（及不适用范围）
- **匹配依据**：经卡一确认材料为含 PVDF 的 `Li/CFx` 氟化碳电极，`C 1s` 呈现典型双特征结构——`~284.8 eV` 导电/sp² 碳峰与 `~290.0 eV` 共价 `C-F` 强峰；同一测点所有精细谱施加统一荷电修正（将 `C-C/C=C` 对齐至 `284.80 eV`）。
- **`O 1s` 处理决策**：默认 `CFx` 预设不含 `O 1s`，因此按卡二原则先执行 **`raw_preview` 原谱预览与信噪比核查**，明确研究问题后再单独构建分峰约束，不盲套参数。

### 2.2 F 1s 为何需要四组候选模型试算对比？
未放电极片的 `F 1s` 常呈现以 **`~688.6 eV`** 为中心的单包络宽峰（半高宽约 `2.0 eV`），而半离子型 `S.I. C-F`（~686.5–687.5 eV）、共价 `C-F`（~687.8–688.8 eV）与 `-CF2 / PVDF`（~688.7–690.2 eV）的化学位移间距小于单峰半高宽，在单包络内**存在强线性共线与多种数学等价解**。因此在 `candidate_models.F1s` 中维护四组对照模型：

| 候选模型 ID | 核心假设与参数区间来源 | 适用判断 |
| :--- | :--- | :--- |
| **`M1_LitStandard_Strict`** | 文献窄窗口模型：`LiF [684.5–685.5]`、`S.I. C-F [686.0–687.2]`、`C-F [687.3–688.4]`、`C-F2(+PVDF) [688.4–689.8]` | 适合峰顶位于 ~688.0 eV 的放电态样品；**若主峰 ≥ 688.5 eV，会强制把 `C-F` 顶死在 688.4 eV 上界**。 |
| **`M2_CFCentered_PeakAnchored`** | 共价主峰锚定模型：基于 `C 1s` 显示共价 `C-F` 占优，把 `C-F` 窗口移至 `[688.1–688.9]` 锚定实测峰顶，配以紧半峰宽相干正则 | 物理自洽性最高，能防止 `C-F2` 反向吞并 `C-F` 主峰。 |
| **`M3_PVDF_Envelope_Split`** | 粘结剂对称拆分模型：允许 `C-F [687.85–688.55]` 与 `C-F2(+PVDF) [688.65–689.60]` 左右分担主峰 | 用于检验极片中 PVDF 贡献在 `F 1s` 主峰内部的不可区分度。 |
| **`M4_NoLiF_3Comp_Organic`** | 无 `LiF` 三组分有机氟模型：结合卡一 `Li 1s` 仅处检出限边缘（`SNR < 3.5`），省略 `LiF` 峰避免低能侧噪声漂移 | 适用于未放电态对照样，检验省略痕量 `LiF` 是否改变有机组分比例。 |

## 3. 工作卡三：审查与敏感性验证

1. **残差欺骗性警戒**：四组模型的 `NRMSE` 均可低于 `0.45%`（$R^2 > 0.999$），**不能仅凭 $R^2$ 高就认定拟合唯一正确**。
2. **参数触界检出**：在 `M1` 中，低结合能侧组分同时顶死区间上界会导致高结合能侧 `C-F2(+PVDF)` 异常膨胀，与 `C 1s` 正交谱结论矛盾。
3. **结论分层口径**：
   - **稳健结论（所有模型一致支持）**：未放电 `Sample 1` 中无机 `LiF` 为痕量本底（`< 1%`，与 `Li 1s` 低信噪比互证），表面氟以有机含氟碳主导。
   - **模型敏感结论（严禁只报单一数字）**：`F 1s` 内 `C-F` 与 `C-F2 (+PVDF)` 随中心窗口假设会显著波动；定量追踪活性 C–F 键演化应以 **`C 1s` 子体系内部占比为优先依据，`F 1s` 在明确锚定模型后做辅助印证，并在总表保留触界与敏感度标记**。

## 4. 工作卡四：交付标准

- 在 `分峰参数与比例汇总` 中保留 `质检与审计标记` 列：`Li 1s` 明确写入 `INFO_TRACE_SIGNAL (SNR < 3.5)`；若某模型发生峰位/FWHM 触界，同步在汇总表与图注标记 `WARN_CENTER_AT_BOUND` / `WARN_FWHM_BOUND`。
- 多候选模型对比同步产出 `(a)-(d)` 对比面板图 + `模型敏感性与参数触界对比表.xlsx`，供审稿人或协作者直接复核模型选择依据。
