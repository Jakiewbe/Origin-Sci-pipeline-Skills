# XPS 与 Raman 物理约束分峰参考（含 Li/CFx 与碳材料适用边界）

> **适用前提**：第 1 节仅适用于氟化碳 `Li/CFx` 体系（其余峰位与模型详见 [Li/CFx 决策案例](./case_cfx_xps_and_f1s_models.md)）；第 2 节仅适用于一阶 `D/G` 碳带明显的碳材料或脱氟碳基底。陌生材料或未建模谱区应先按工作卡二执行 `raw_preview` 原谱预览，再单独制定约束方案。

## 1. XPS 核心物理约束（Li/CFx 极片与粉末示例）

1. **荷电校正互锁准则（Charge Referencing）**：
   - 常规粉末或浅度放电样品以污染碳/导电炭 `C-C/C=C = 284.8 eV` 为主锚点。
   - **放电态极片特别护栏**：深放电生成大量绝缘态 `LiF` 时可能出现差异荷电。校正平移量 $\Delta E$ 确定后，**同一测试点的所有精细谱（C 1s, F 1s, Li 1s, O 1s）必须施加完全相同的 $\Delta E$**，并交叉核验 `F 1s` 中 `LiF` 峰位是否落在 `685.0 ± 0.4 eV`（即 `F 1s(LiF) - C 1s(C-C) ≈ 400.2 eV`）。
2. **基线与线型约定**：
   - 强阶跃精细谱（`C 1s`、`F 1s`）默认采用迭代 **Shirley 基线**；弱信号或平坦背底谱区（如痕量 `Li 1s`）采用端点平均 **Linear 基线**，防止 Shirley 在高噪区产生S型伪畸变。
   - 线型采用面积归一化的 **Pseudo-Voigt**（$20\% \sim 30\%$ Lorentzian + $70\% \sim 80\%$ Gaussian）。
3. **双口径定量汇报（解决导电剂/粘结剂稀释效应）**：
   - 极片中含有导电炭（Super P / CNT）与粘结剂（PVDF），直接看 `C 1s` 总面积占比会受炭黑配比主导。
   - 汇总表必须同时输出两套比例：
     - **全谱区占比 (%)**：各组分占整个 `C 1s`（或 `F 1s`）总拟合面积的百分比；
     - **活性含氟子体系内部占比 (%)**：例如在 `{S.I. C-F, C-F, C-F2(+PVDF)}` 内部重新归一化的百分比，用于精准追踪半离子 C–F 与共价 C–F 的选择性消耗规律。
4. **Origin 数据簿强制“含基线”列规范**：
   - 在导出 `.xlsx` 与 `.opju` 时，每个子峰曲线必须存为 **`Baseline + Net_Component`（含基线列）**！
   - 原因：XPS 基线是倾斜或阶跃的，只有存为含基线列，在 Origin 中与 `Backgnd.` 列叠加作图或设置填充到底部基线时，视觉峰形才与包络线严格闭合。

## 2. Raman 碳结构四峰分峰与多测点统计规范

1. **一阶碳带（850–1950 $\text{cm}^{-1}$）标准四峰模型**：
   - **$D^*$ (~1185 $\text{cm}^{-1}$)**：$\text{sp}^3$ 无定形边缘 / 含氟碳晶格畸变振动带（Pseudo-Voigt，$\eta \approx 0.2$）。
   - **$D$ (~1345 $\text{cm}^{-1}$)**：$A_{1g}$ 呼吸振动模式，反映芳香环边缘与面内缺陷（Lorentzian 为主，$\eta \approx 0.75$）。
   - **$D''$ (~1505 $\text{cm}^{-1}$)**：无定形碳间隙与乱层堆垛贡献（纯 Gaussian，$\eta = 0$，防止抢夺 $D/G$ 洛伦兹翼面积）。
   - **$G$ (~1588 $\text{cm}^{-1}$)**：$E_{2g}$ 面内 $\text{sp}^2$ 碳伸缩振动，反映放电脱氟后石墨化碳骨架的恢复（$\eta \approx 0.65$）。
2. **双指标并行汇报**：
   - 同时计算并汇报 **净峰高比 $I_D / I_G$** 与 **积分面积比 $A_D / A_G$**。在短脉冲极端放电中，局部无序展宽常导致 $I_D/I_G$ 略降而 $A_D/A_G$ 显著上升，双指标对比能揭示缺陷形态演化。
   - 面内微晶尺寸估算（Tuinstra–Koenig 关系，532 nm 激发）：
     $$L_a (\text{nm}) = \frac{2.4 \times 10^{-10} \lambda_{\text{nm}}^4}{A_D / A_G} \approx \frac{19.22}{A_D / A_G}$$
3. **多测点统计准则**：
   - 每个极片通常采集 3 个独立微区测点（如 `S1_spot1.txt, S1_spot2.txt, S1_spot3.txt`）。必须先逐条去宇宙射线尖峰并独立拟合，计算 `均值 ± SD`，选取最接近均值的测点作为组图代表谱。
